## Importante

- El panel ahora es Moss, una app aparte. Tu contenido vive en un cerebro: un repo con `moss.config.json`.
- El estado local (encargos, ajustes, cachés) pasa a `<cerebro>/.moss/`.

## Nuevo

- Bienvenida al abrir: elegir una carpeta, clonar un repo de GitHub o crear un cerebro nuevo. «Archivo → Abrir otro cerebro…».
- Varios agentes: Claude Code, Codex, Cursor, OpenCode, Gemini CLI o un comando propio.
- Icono nuevo de Moss (brote) y registros en `~/Library/Logs/Moss/`.

## Mejorado

- Detener un encargo cierra también los procesos que lanzó el agente. Un agente colgado 20 minutos se detiene solo.
- Un encargo cortado por cerrar la app queda como interrumpido y se puede retomar.
- El servidor local exige un token por arranque y solo acepta peticiones de este equipo.
- Redes, cadencia, rutas, reglas y comprobaciones al publicar salen del `moss.config.json` del cerebro.
